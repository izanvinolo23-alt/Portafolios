Lista de Definición

Objetivo: Hacer una lista con términos relacionados con el mundo web y su definición.

HTML
Lenguaje de Marcado de Hipertexto. Es el lenguaje estándar para la creación de páginas web y su estructura.
CSS
Hojas de Estilo en Cascada (Cascading Style Sheets). Se utiliza para describir la presentación de un documento escrito en un lenguaje de marcado como HTML.
JavaScript
Lenguaje de programación, principalmente utilizado para crear elementos interactivos en las páginas web (front-end) y también en el servidor (back-end).
Navegador
Aplicación de software que permite a los usuarios acceder y visualizar páginas web, como Chrome, Firefox, Safari o Edge.
Página web
Documento electrónico, típicamente escrito en HTML, accesible mediante un navegador a través de Internet o una red local.
E-commerce
Comercio electrónico. Consiste en la compra y venta de bienes o servicios a través de medios electrónicos, principalmente Internet.
W3C
Consorcio de la World Wide Web. Es la organización internacional que desarrolla los estándares para la World Wide Web.
Internet
Red pública y global de ordenadores interconectados que utilizan un conjunto estándar de protocolos (TCP/IP) para la comunicación.
